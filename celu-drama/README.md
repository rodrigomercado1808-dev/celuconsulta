# Celu Dramático — sitio web vanilla

Mini sitio responsive para atraer consultas de reparación con un test divertido de orientación inicial. Está hecho con HTML, CSS y JavaScript puro: no necesita instalar nada ni usar frameworks.

## Probarlo

Abrí `index.html` en un navegador. Para probarlo como sitio local, podés usar cualquier servidor estático local; no requiere compilación.

## Personalizar los datos

En `app.js`, al principio, editá:

- `whatsappNumber`: número internacional, solo dígitos y sin `+`. El valor inicial corresponde al WhatsApp que figura en el afiche (formato de enlace de Argentina); probá el botón para confirmar que abre tu chat correcto.
- `location`: zona de atención.
- `businessName`: nombre del emprendimiento.

También podés cambiar textos, servicios y colores directamente en `index.html` y `styles.css`.

## Publicarlo

Subí los archivos `index.html`, `styles.css` y `app.js` a un hosting estático. GitHub Pages, Netlify y Cloudflare Pages tienen opciones gratuitas para sitios estáticos. No hace falta backend.

## Cómo genera oportunidades

El test termina con un enlace de WhatsApp que prepara un mensaje con las respuestas elegidas. El sitio no cobra ni garantiza ingresos: sirve para convertir visitas en consultas; conseguir clientes depende de compartir la página, la zona y la demanda.

## Privacidad y alcance

El sitio no envía ni guarda respuestas. El resultado es orientativo y no reemplaza un diagnóstico técnico. No promete que una reparación sea posible sin revisar el equipo.
